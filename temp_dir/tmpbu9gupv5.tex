\section{Introduction}
Bubble Sort is a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements and swaps them if they are in the wrong order. The pass through the list is repeated until no swaps are needed, which indicates that the list is sorted.

\section{Java Implementation}
Below is the Java code implementation of the Bubble Sort algorithm:
\begin{lstlisting}[language=Java, frame=single, numbers=left, basicstyle=\ttfamily\small, showstringspaces=false]
public class BubbleSort {
    public static void bubbleSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - i - 1; j++) {
                if (arr[j] > arr[j + 1]) {
                    // swap arr[j+1] and arr[j]
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }
    }

    public static void main(String[] args) {
        int[] arr = {64, 34, 25, 12, 22, 11, 90};
        bubbleSort(arr);
        System.out.println("Sorted array:");
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " ");
        }
    }
}
\end{lstlisting}

\section{Time Complexity}
The time complexity of Bubble Sort is:
\begin{itemize}
    \item \textbf{Worst and Average Case:} O(n$^2$), where 'n' is the number of items being sorted. This occurs when the array is in reverse order.
    \item \textbf{Best Case:} O(n), when the array is already sorted.
\end{itemize}

\section{Conclusion}
Bubble Sort is a simple algorithm to understand and implement, but it is inefficient for large datasets due to its quadratic time complexity.
